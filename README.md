# עדן חדד - שיעורים פרטיים בגובה העיניים

דף נחיתה מינימליסטי ונקי המציג שיעורים פרטיים לתלמידי בית ספר מאת עדן חדד (גבעתיים והסביבה / אונליין).

## טכנולוגיות
- **Next.js** (App Router)
- **Tailwind CSS** (כולל תמיכה מלאה ב-Dark Mode וכיווניות RTL)
- **Lucide React** (אייקונים)

## הרצה מקומית
```bash
npm install
npm run dev
```
